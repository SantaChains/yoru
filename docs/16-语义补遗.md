> 状态：定稿。来源：2026-10-11 第五/六/七轮语法对话。**优先级约束：编译快 > AI 错误少 > 热重载 > 其余**。本文档封闭 15 号未覆盖的语义空洞（Tier A 决策 29-32 + **Tier B 已升格为正式决策 33-39** + Tier C 不做清单），并收录工具链五个盲区（16.4）。第七轮家族补扫见 [17 号](17-家族补扫与设计打磨.md)（决策 40-43）。

## 16.0 决策速览

| # | 决策 | 内容 | 依据 |
|---|---|---|---|
| 29 | 溢出抛错 | 加/减/乘溢出 = 运行时错误（可熔断计数）；环绕需求走显式变体 `+% *%`（P2） | Java 抛/C#/Go 环绕/Rust debug 抛/C UB 五阵营分裂，静默环绕是面试级头名坑；Swift 同默认；确定性沙盒必须定义 |
| 30 | 深相等 + Ord 协议 | `==` 深结构比较（值语义推论）；排序/Map 键走 `protocol Ord`（`cmp(a,b) -> int` 返回 -1/0/1，无减法溢出陷阱）与 `Hash`；`[K: V]` 的 K 约束 Hash+Ord；浮点 `==` 保留 IEEE（NaN≠NaN） | OCaml 多态比较之害（Real World OCaml 整章）；比较器减法溢出反转排序（C#/Java 实证） |
| 31 | 闭包按值快照 | 捕获 = 建闭包那一刻的值快照；捕获 `let mut` 局部变量 → typeck 报错并提示先 `let` 快照 | 与值语义同构（无共享可变）；C# 循环变量按引用捕获、Go loop var 六年修复是实锤；一句话可教 |
| 32 | pub 显式导出 | 默认私有，`pub` 前缀显式导出（可 grep）；**`pub fn` 即宿主可见入口**（名字即协议，宿主 manifest 直接引用）；`import ... as` 别名；禁止遮蔽 stdlib 名 | 草案原本无任何可见性——词汇表会被私有函数污染；MoonBit `pub(open)`/Rust 双先验 |

Tier A 其余三项直接采纳推荐（无争议）：**递归允许**但受 VM 栈深上限（与内存预算、指令预算并列第三资源，溢出 = StackOverflow 错误可熔断）；**TCO 不承诺**（Python 拒绝 TCO 的理由——完整栈追踪——对 AI 调试更有价值，尾递归优化 P2）；**泛型约束** `fn sort<T: Ord>(xs: [T]) -> [T]`，编译期单态化（字节码按类型实例化）。

## 16.1 Tier B：已升格为正式决策 33-39（2026-10-11 第七轮定稿）

| # | 决策 | 内容 | 依据 |
|---|---|---|---|
| 33 | UTF-8 唯一编码 | 字符串 = UTF-8 唯一编码（Plan 9 发明 UTF-8 的正统传承）。迭代按码点；`string.len` 取字节数（O(1) 且诚实）；切片按码点索引、非边界/越界 = 运行时错误；**比较 = 字节序，locale 排序永不进内核**（collation 是宿主能力） | FluxDown filter.rs 跨实现 Unicode regex 对齐之痛 = 不做此决定的代价；Go/Rust/Swift 同路线 |
| 34 | Result 忽略 = 警告 | 忽略 `Result` = typeck 警告，显式 `let _ =` 才可丢弃 | C++ `[[nodiscard]]`、Go errcheck 都在还债，Yoru 零成本拿到 |
| 35 | 浮点确定性承诺 | VM 逐指令执行（无 FMA 融合、无重排、无扩展精度寄存器滞留）⇒ IEEE754 跨平台天然确定 | 13 号识别的「无确定性浮点承诺」缺口就此关闭；游戏联机同步的前提 |
| 36 | Map 迭代序 = 插入序 | `[K: V]` 迭代按插入序，确定性可测 | Python 3.7+ 先验；Java HashMap 随机序反面教材 |
| 37 | 移位越界抛错 | 移位量 ≥ 位宽 = 运行时错误；右移为算术移位 | 与决策 29 同哲学：算错了就响 |
| 38 | 字面量增强 | `0x` 十六进制（游戏颜色刚需）、`1_000_000` 下划线分隔、浮点科学计数 | 词法层小改，不影响关键字冻结 |
| 39 | 禁嵌套 Option | `T??` typeck 直接拒绝 | canonical form；Swift 同禁 |

## 16.2 Tier C：不做清单（防范围蔓延）

- 无元组类型（record/struct 足够）。
- 无 goto/label。
- **无内建正则引擎**——正则的 Unicode 对齐是深坑（FluxDown 实证），留给宿主或 L2 注入。
- 无 locale 感知比较/排序。
- 无 `T??`、无隐式数值转换（决策 26）、无 dynamic（决策 28）。

## 16.4 工具链五个盲区（「AI 错误少」的另一半：语法管生成，工具链管反馈）

| # | 盲区 | 设计要点 | 证据 |
|---|---|---|---|
| T1 | **语言纪元与演进策略** | semver + deprecation 流程 + epoch 模型 day-1 入档；breaking 变更走实验旗标双轨 | Mojo 1.0 稳定纪元宣言、Mojo 避免重蹈 Python2→3；Leo White：语言演进的错误几乎不可逆 |
| T2 | **elm diff 式兼容自动检测** | 类型签名完备 ⇒ API 变更级别（major/minor/patch）可机械判定；`l diff` 子命令输出宿主 API/stdlib 升级摘要 | Elm 全自动强制 semver（NoRedInk 无 PATCH 惊喜）；Yoru 的签名即契约免费获得此能力 |
| T3 | **canonical formatter** | gofmt 式唯一格式化器随工具链发布；格式即规范形式的运行时保障（AI 生成 → format → diff 只剩语义） | gofmt 消灭风格争论；Elm format 的「保存即归位」幸福感 |
| T4 | **错误消息规范** | 四要素：type diff（只显示差异字段）/ expected-vs-actual / beginner hint / **机器可应用修复建议（patch 输出）**；JSON 诊断升级为含结构化 fix 的 schema | Elm「编译器即助手」系列；MoonBit `moon ide rename` 直接输出 ready-to-apply patch——AI 修复闭环的终点形态 |
| T5 | **注册表 + doctest + 属性测试** | 包注册表治理（mooncakes 先验）；文档注释 `///` + doctest（示例即测试即词汇表样本）；QuickCheck 式属性测试 P1 | MoonBit mooncakes.io；Rust doctest；Haskell QuickCheck 传统 |
