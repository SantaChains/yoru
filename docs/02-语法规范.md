## 2.1 词法规则

```
identifier ::= [A-Za-z_][A-Za-z0-9_]*
integer    ::= [0-9]+
float      ::= [0-9]+ "." [0-9]+
string     ::= '"' (any-char-except-quote | escape)* '"'
```
- 注释：// 行注释；/* */ 块注释。
- 空白与换行是分隔符，无缩进语义（避免布局歧义，AI 生成不易错）。

关键字（保留字）：`let const fn struct enum match if else while for in return import export type true false nil as try throw async await mut`

运算符：`+ - * / % == != < > <= >= && || ! = += -=`（赋值）`& | ^ << >> >>>`（位运算）`->`（函数类型）`|`（联合类型）`?`（Option 简写）`::`（显式转换）

说明：位或 `|` 仅在表达式上下文（位运算），联合类型 `|` 仅在类型上下文，语法上下文严格分离。

## 2.2 语法规则（EBNF）

```
program    ::= { import_decl | type_decl | item_decl }
import_decl ::= "import" identifier "from" string ";"
type_decl  ::= "type" identifier "=" type ";"
item_decl  ::= fn_decl | struct_decl | enum_decl | const_decl

fn_decl    ::= "fn" identifier [ "<" type_param { "," type_param } ">" ] "(" params ")" [ ":" type ] block
params     ::= [ param { "," param } ]
param      ::= identifier [ ":" type ]

struct_decl ::= "struct" identifier [ "<" type_param { "," type_param } ">" ] "{" { field_decl } "}"
field_decl ::= identifier ":" type ";"
enum_decl  ::= "enum" identifier [ "<" type_param { "," type_param } ">" ] "{" { variant } "}"
variant    ::= identifier [ "(" type ")" ]

block      ::= "{" { stmt } "}"

stmt       ::= let_decl | const_decl | expr_stmt | if_stmt | while_stmt | for_stmt | match_stmt | return_stmt | throw_stmt | block
let_decl   ::= "let" [ "mut" ] identifier [ ":" type ] "=" expr ";"
const_decl ::= "const" identifier [ ":" type ] "=" expr ";"
expr_stmt  ::= expr ";"
if_stmt    ::= "if" expr block [ "else" ( block | if_stmt ) ]
while_stmt ::= "while" expr block
for_stmt   ::= "for" identifier "in" expr block
return_stmt ::= "return" [ expr ] ";"
throw_stmt ::= "throw" expr ";"
match_stmt ::= "match" expr "{" { match_arm } "}"
match_arm  ::= pattern "=>" ( expr | block ) ","
pattern    ::= literal | identifier | variant_pattern | "_"
variant_pattern ::= identifier [ "(" identifier ")" ]

expr       ::= literal | identifier | call_expr | member_expr | index_expr | unary_expr | binary_expr | assign_expr | lambda_expr | group_expr | async_expr
call_expr  ::= expr "(" [ expr { "," expr } ] ")"
member_expr ::= expr "." identifier
index_expr ::= expr "[" expr "]"
unary_expr ::= ( "!" | "-" ) expr
binary_expr ::= expr binop expr
assign_expr ::= identifier ( "=" | "+=" | "-=" ) expr
lambda_expr ::= "fn" "(" params ")" [ ":" type ] block
group_expr ::= "(" expr ")"
async_expr ::= "async" block

literal    ::= integer | float | string | "true" | "false" | "nil"

type       ::= prim_type | identifier | generic_type | option_type | result_type | union_type | fn_type | list_type | record_type | "dynamic"
prim_type  ::= "int" | "float" | "bool" | "string" | "unit"
generic_type ::= identifier "<" type { "," type } ">"
option_type ::= type "?" | "Option<" type ">"
result_type ::= "Result<" type "," type ">"
union_type ::= type "|" type
fn_type    ::= "(" [ type { "," type } ] ")" "->" type
list_type  ::= "[" type "]"
record_type ::= "{" field_decl { field_decl } "}"
```

## 2.3 语法设计注释

1. 表达式文法按优先级分层实现（递归下降），此处合并表述。
2. type 文法与表达式文法严格分离（类型上下文无运行时求值）。
3. 无缩进语义、分号必写（AI 生成不易错）。
4. 赋值仅限标识符（无解构赋值，MVP 简化）。
5. Option 简写 `T?` 与 Luau 一致。
6. 变量声明关键字确认 let/const。备选：`local` 作为 let 同义别名（成本极低），暂不采纳以保持关键字最小集；若受众偏 Lua 系可低成本恢复（决策3）。
