# Yoru设计文档（体系化）

状态：设计阶段完成（v0.5 拆分版），进入实现阶段。设计1-13 全部定稿，详见下方文档地图。

## 定位（一句话）

一门**宿主无关、渐进类型、默认局部作用域、值语义、沙盒优先**的嵌入式脚本语言，面向 Rust 宿主生态，以**游戏数学与底层运算**为领域定向，支持**字节码→JIT→AOT** 三档执行。生态位：宿主应用内的 Lua 替代（插件/配置/扩展/AI 生成片段），不锁死任何宿主（Tauri 仅场景之一）。

## 内核三支柱（最优先理解）

1. **渐进类型分级**：nonstrict 快速脚本 + strict 可健全，同一实现不同错误抑制策略（Luau 思路），区别于 TS 的单一不健全路线。
2. **值语义 + 默认局部作用域**：无共享可变状态、无隐式全局，热重载与沙盒审计天然安全。
3. **宿主无关的沙盒执行**：默认零权限，能力经 FFI 显式注入；虚拟机纯 Rust 可跨平台。
