# 08 必要实现清单与生态边界

[上一章：07 路线图](07-路线图.md) | [目录](README.md) | [下一章：09 学习借鉴](09-学习借鉴.md)

定位复核（用户确认）：新时代高性能安全、容易接入其他语言的 Lua、编译和嵌入快速轻量。

## 8.1 必要实现分层（每层标注缺失后果）

### 第一层 可嵌入内核（缺此则不成语言）
1. Lexer/Parser：递归下降 + 错误恢复 + 源码位置。缺失后果：无前端。
2. 类型检查器：nonstrict/strict 渐进核心。缺失后果：失去类型安全卖点。
3. 字节码编译器：AST→栈式字节码。缺失后果：无法执行。
4. 解释器 VM：编译期最大栈深、快速指令分派。缺失后果：无运行时。
5. 值表示：tagged enum。缺失后果：无法表示程序值。
6. 闭包：upvalue 机制。缺失后果：函数一等公民不成立。
7. 模块系统：import/export + 模块字节码。缺失后果：无法组织脚本。

### 第二层 安全与资源（缺此则"安全"定位不成立）
8. 每 VM 独立堆 + 资源限制（内存上限、指令超时、栈深上限）。缺失后果：死循环可拖垮宿主。
9. 沙盒默认零权限 + capability 注入模型。缺失后果：脚本可越权。
10. GC/引用计数。缺失后果：内存泄漏或悬挂引用。
11. 无 UB 保证：内置操作边界检查（越界→Result 或运行时错误）。缺失后果：脚本可触发 UB。

### 第三层 嵌入与互操作（缺此则"容易接入其他语言"不成立，这是 Lua 的灵魂）
12. Rust 宿主 API：创建 VM/加载模块/调用函数/注入命令/错误提取。
13. FFI 类型映射：Rust struct↔Yoru 类型，derive 宏自动生成绑定。
14. CallHost 指令 + 宿主函数签名校验。
15. C ABI（阶段1）：让 C/C++/Zig/其他语言可嵌入（Lua C API 模式）。

### 第四层 开发者体验（缺此则"新时代"不成立）
16. 结构化诊断：人类可读 + JSON 输出。
17. REPL。
18. 热重载。
19. 增量编译（阶段1）。

### 第五层 性能路径（缺此则"高性能"不完整，可分阶段）
20. opcode fusion / PIC（P1）。
21. 单层 JIT（P2，Cranelift）。
22. AOT 双后端（P3）。

### 第六层 标准库最小集（缺此则脚本无法做事）
23. core/math/string/list/map/option/result/ffi。

核心三件套判定：资源有限时最小可成立组合为 第一层+第二层+第三层；标准库随后补；性能路径最后补。

## 8.2 与 MoonBit 的生态边界（防重合声明）

MoonBit 现状（官方资料核实，2026-09）：通用型语言+工具链，Wasm 优先（wasm/wasm-gc/js/native/LLVM），静态强类型（HM+双向检查），模式匹配、trait、错误效果追踪，Perceus 内存模型（Wasm/C 后端引用计数、WasmGC/JS 后端运行时 GC），自带 moon 构建+mooncakes 包管理+IDE+在线 IDE+AI agent，Beta 阶段（v0.10.x），hello world Wasm 27KB，4000 包编译 <7 秒。作者张宏波：OCaml 核心维护者、ReScript 创始人、Flow 参与者。

结论：Yoru 与 MoonBit 生态重合度极低，定位互补，不构成竞争。

| 维度 | MoonBit | Yoru |
|---|---|---|
| 生态位 | 独立主语言（Rust/Go 位，完整应用/库，云边部署） | 宿主内脚本层（Lua 位，插件/配置/AI 片段） |
| 执行模型 | AOT 编译，无解释器 | 解释器优先，字节码→JIT→AOT 三档，热重载 |
| 类型系统 | 全静态强类型（无 dynamic） | 渐进类型（nonstrict/strict，dynamic 存在） |
| 宿主关系 | 自带 runtime/GC/WASI | 依赖宿主注入能力（FFI 是灵魂） |
| 工具链 | 一体化（构建+包管理+IDE+AI） | 内核极小，无独立工具链，走宿主集成 |
| 内存机制 | Perceus 编译期复用优化 | MVP 运行时引用计数 |

可借鉴 MoonBit 不照搬定位：错误效果追踪（P2 评估）、增量编译（已列入阶段1）、AI 结构化诊断增强。不做：独立构建系统、包管理、Wasm 一等公民、IDE 生态。

互补共存：MoonBit 写核心计算组件，Yoru 作为宿主应用（Rust/Tauri/游戏引擎）内脚本层。

## 8.3 非必要（明确不做，防范围膨胀）

包管理器、LSP、IDE、宏系统、完整泛型、多返回值、类型级编程、GC 分代、多层 JIT。
