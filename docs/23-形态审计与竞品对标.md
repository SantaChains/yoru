## 23.1 结论先行

1. **形态判定**：Yoru 当前是 **「Lua 5.4 的运行时哲学 × TypeScript 的静态外观 × Rust 的内核纪律」的三混血语言**，外加一项竞品均无的独有轴——**AI 优先**（约束语法 + 可枚举内建注册面 + 结构化诊断）。
2. **注册表统一收口（决策 77）已交付**（本轮），typeck/lower/VM 三面漂移的六项实测缺陷全部消除，workspace **107 测试全绿 + clippy 零告警**。
3. **截图三条裁决全部尊重**：arena/热重载双版本原子换表**不做**（无 benchmark 依据）；树遍历参考解释器差分测试**归阶段 6**；`print` typeck 面未对齐**归阶段 4 注册表收口**（= 本轮交付物）。
4. **最大短板是测试密度**：产品 ~11.8k 行 / 测试 ~1.4k 行（**0.12:1**），距 SQLite 590:1 的标杆差两个数量级——这是阶段 6 的主战场，而非当前阶段 4 的负债。
5. **最值得补的三项**（按收益/成本排序）：诊断 Applicability 分级（rustc 范式，低成本）→ doctest 注册表示例可执行（中成本，AI 受益最大）→ 差分 fuzz 双引擎（高成本，阶段 6）。

## 23.2 血缘分析：像什么，融合了什么

| 来源 | Yoru 吸收的具体形态 | 证据（代码/决策） |
|---|---|---|
| **Lua 5.4** | 值即动态类型 + 局部作用域默认 + `import x from "std"` 模块制 + Lua 式递归 upvalue 捕获链 + require 式热重载语义 + 错误码域（Y-T/Y-R/Y-H/Y-S/Y-I） | 决策 68-72；lower upvalue 链；demo require |
| **TypeScript** | `<T>` 泛型 + `as` 唯一显式转换 + `T?` Option 通道 + struct/tag 声明 + **比 TS 更激进的渐进类型**（nonstrict/strict 双模式同一实现，决策：TS 是单一不健全路线） | 决策 26/27/40；03 号 |
| **Rust** | distinct newtype + protocol impl（trait 投影）+ Result/tag 错误 + `pub` 显式导出 + match 全路径收束分析 + 安全闸思维（三限/深度/链长） | 决策 23/21/75；check.rs block_always_terminates |
| **Odin / Jai** | DOD 哲学 + 编译速度优先 + 零隐藏行为（注册表 const 构造、零分配 Param DSL） | 决策 77；stdlib 427 行 |
| **Gleam** | 健全类型系统目标（strict 模式）+ 无 null（nil 走 Option 智能收窄） | 决策 40；03 号 |
| **Starlark** | 确定性执行 + frozen values 的近似（COW 值语义：Rc 引用计数==1 原地写，无共享可变） | VM value.rs COW |
| **竞品均无（独有）** | **AI 优先**：Anka DSL 约束语法（arXiv 2512.23214 实证 +40pp over Python）+ 内建注册表面可枚举（26 条单一事实源）+ JSON schema v1 结构化诊断 + did-you-mean fix-it | 14 号；决策 77；schema 快照测试 |

**一句话形态**：一门写给 AI 写、给 Rust 宿主嵌的「小语言」——语法像 TS 那样可被静态约束，运行时像 Lua 那样简单可预测，错误处理像 rustc 那样结构化，但没有一门现有语言同时押注这四端。

## 23.4 合理取舍盘点

**已做且正确的取舍**（证据驱动，勿翻案）：

| 取舍 | 依据 |
|---|---|
| 栈式字节码冻结 | 决策 68：寄存器式仅在 JIT 立项时重估（Luau 寄存器式服务 JIT 的实证） |
| arena AST / 热重载双版本换表**不做** | 截图裁决 + 无 benchmark 依据；arena 侵入全部 AST 消费者，换表与决策 72 观测面冲突 |
| 每内建三张平行表 → 单一注册表 | 决策 77：六项三面漂移实测缺陷的根因就是「无单一事实源」 |
| CallHost 不发射、走 Const(Str) 同构 | 决策 76：免 call 位前瞻，保持名字解析单一职责 |
| 形式化验证/JIT/AOT 后置 | 阶段未到；05 号后端路线已留 |

**可改进且成本可控的点**（按优先级）：

1. **诊断 Applicability 分级**（rustc 范式）：当前 `suggestions: Vec<String>` 无适用度语义，AI 消费方无法区分「可自动应用」与「仅提示」。改法：`Suggestion { text, applicability }` 四级枚举，schema v1 升 v2（快照测试同步）。
2. **doctest 注册表示例**：26 条内建的 `doc` 字段升级为可执行 doctest（20 号已列阶段 5，stdlib 100% API 覆盖退出标准）——**AI 受益最大**：示例即契约。
3. **`yoru differential` 工具**：树遍历参考解释器差分（归阶段 6，wasmtime Tier1 范式）。
4. **测试密度**：0.12:1 → 阶段 6 目标 ≥1:1（rustc 量级），发布门槛 590× 精神取 MC/DC + mutation 组合达标即可，不追求字面 590×。
5. **错误消息的「同类先例」引用**：Y-T0003 等可带「决策 N」溯源标签（部分已有，未全覆盖）。
