# 31 内存与所有权模型（权威文档）

> 证据基准：`yoru-vm/src/lib.rs`（COW 三路径）、`yoru-bytecode/src/lower.rs`（upvalue 链）、决策 13/31/36/41/71/72/80。

## 31.1 结论先行

Yoru 的内存模型一句话：**值语义 + 写时复制（COW）+ 按值快照闭包，语言面不存在可变别名**。共享发生在底层（`Rc` 引用计数），但任何写操作都会先判定独占性——不独占即复制后改——因此从语言 observable 行为看，赋值、传参、捕获都是值的快照，`a = b` 之后 `a` 与 `b` 永远独立。

三支柱：

1. **COW 值语义**（决策 13）：容器（List/Map/struct）变更前判 `Rc::strong_count == 1`——独占则原地改，共享则深拷贝副本后改副本。
2. **可变性双门**：`let mut` 声明门（决策 47 族）× lvalue 归属门（决策 41：仅 owned 的局部/字段/索引可赋值）。
3. **闭包按值快照**（决策 31）：lambda 捕获是快照，写入闭包自身快照槽，不回写外层——无共享可变态。

## 31.2 值语义与 COW（决策 13）

底层表示：容器为 `Rc<RefCell<Vec<Value>>>` / `Rc<RefCell<MapBox>>` / `Rc<RefCell<StructObj>>`。**绑定、传参、字段存取共享 `Rc`，不拷贝数据**；拷贝只发生在「写」的时刻：

| 变更路径 | 独占判定 | 独占（refcount==1） | 共享 |
|---|---|---|---|
| 列表 `with_list_mut` | `Rc::strong_count(&l) == 1` | 原地 `borrow_mut` 写 | `clone()` 全量拷贝 → 改副本 → 返回新 `Rc` |
| 映射 `with_map_mut` | 同上 | 原地更新（保持插入序，决策 36） | 同上 |
| struct `with_struct_mut` | 同上 | 原地写（P0b 静态槽位快路径 + fid 复核） | 同上 |

语义推论（可依赖的 observable 行为）：

- `let a = b; a[0] = 1` 不影响 `b`——写时 `a` 的容器 refcount ≥ 2（b 仍持有），必然走拷贝。
- 拷贝成本**计入堆配额**（`alloc` 计费，决策 71/72 资源三限）——大容器反复跨引用写 = O(n) 每次，是性能基线（24 号）的已知计量面。
- 深相等（决策族）与 COW 配合：键比较走 `deep_eq`，无标识符可比性——语言没有 `===`（引用相等），因为没有可观测的共享。

## 31.3 可变性门与赋值目标

赋值合法 = 双门同时通过：

1. **声明门**：目标根必须是 `let mut` 声明（不可变绑定赋值 = typeck 拒绝）。
2. **归属门**（决策 41）：lvalue 链 `ident { .field | [idx] }` 的每一段走 owned 语义——字段/下标赋值经「副本入临时 + 写回槽位」保证值语义。

实现侧快路径（决策 80）：赋值目标 base 为局部变量时 lower 发射 `SetIndexLocal slot`——直写局部槽，规避「栈上容器副本 + 局部槽双重引用」使 COW 互斥判定恒不成立、退化为每次整表拷贝的性能陷阱（T2b 基线实测驱动）。**语义与通用路径完全一致，仅免拷贝。**

## 31.4 闭包与捕获（决策 31）

- lambda 捕获走 **Lua 式 upvalue 链**：内层 lambda 捕获外层局部，经中间层 proto.upvalues 逐层传递（D-24 根修后的 move 语义继承）。
- **捕获即按值快照**：lambda 体内对捕获名的赋值写入**闭包自身的快照槽**，不回写外层作用域。
- 推论：闭包无共享可变态 → 收窄失效分析（决策 40「重新赋值即失效」）与别名失效分析解耦；闭包按值快照保证无别名失效。
- 语言面**无** `&mut` 捕获、无 RefCell 式内部可变性——跨闭包的可变通信只能经容器返回值或宿主能力。

## 31.5 别名面与环安全

- **无可变别名**：COW + 快照捕获的联合推论。任何两个名字在任何时刻都不共享可变视图。
- **迭代快照**：Map 迭代产出键快照（`Cursor::Map`，决策 31/36）——迭代中变异不影响进行中迭代；List 迭代序 = 插入序。
- **Rc 环**：语言面**不可构造**引用环——环需要「共享 + 可变」同时成立，本模型两者都封死。唯一环注入通道是宿主能力（宿主构造自引用容器）。实现不做环检测/弱引用——嵌入宿主若注入环，泄漏责任在宿主侧（嵌入纪律：宿主值自有其生命周期管理）。

## 31.7 已知边界（诚实清单）

- **拷贝是深拷贝**：嵌套容器 COW 拷贝为整树 clone——大树上单字段写 O(树)。无写时复制共享子树优化（工程候选，未排期）。
- **refcount 判定非精确所有权**：`strong_count==1` 是启发式独占判定（栈上临时 + 槽位会短暂抬高计数）——决策 80 快路径就是为绕开这个不精确性而生的特例，通用路径维持保守拷贝。
- **跨宿主值的 COW**：宿主注入的容器若被语言侧共享写，同样走拷贝路径——宿主若依赖「传入引用被原地改」的语义，将被本模型静默违背（宿主注册表文档须声明值语义，12.2）。
