# 06 标准库与领域能力

[上一章：05 后端取舍](05-后端取舍.md) | [目录](README.md) | [下一章：07 路线图](07-路线图.md)

## 6.1 标准库分层（Lua/QuickJS 验证模式）

三层分离：引擎核心（零 I/O，纯计算）→ 标准库模块（可选加载，QuickJS std/os 模式）→ 宿主 FFI（能力注入）。内核极小，能力走库与宿主。沙盒默认零权限：标准库模块按需启用，I/O 与系统能力一律经宿主注入。

## 6.2 MVP 标准库清单

- core：print/assert/typeof/panic
- math：abs/floor/ceil/sqrt/sin/cos/atan2/min/max/clamp/lerp/pi
- string：len/upper/lower/trim/split/join/contains/replace/format（printf 风格）
- list：push/pop/get/set/len（方法形式）
- map：get/set/has/keys/len
- option/result：is_some/is_none/unwrap（非空路径由类型系统保证）/map
- ffi：宿主命令注册与调用入口

## 6.2.1 内建注册表（决策 77，T2a 落地 2026-10-12）

**实现即权威**：26 条内建签名单一事实源 = `yoru-stdlib::BUILTINS`（`Builtin { name, module, params, variadic, same_numeric, ret, doc }`）。typeck 面 / lower 名单 / VM 分派三处由测试对账收敛，**新增内建只改注册表一处**。

| 类别 | 内建 | 模块别名 | 签名要点 |
|---|---|---|---|
| 输出/断言 | print | — | 变参，参数面 `Any`（VM 接受任意值） |
| | assert | — | `(bool, string?)`；Opt 尾参可省 |
| 聚合 | len | string | `Coll → int`（软类型 Coll = str\|list\|map） |
| 数学 | abs/min/max | math | `same_numeric`：int/float 同型（决策 26 不隐式混合）；abs 返回位落地实参类型 |
| | sqrt | math | `float → float`（不收 int） |
| | floor/ceil | math | `float → int`（非有限抛错；2^63 界检查） |
| 区间 | range | — | 两条元数重载 `(int)` / `(int, int)` → Range；for 迭代为 int（VM ForPrep 同构） |
| 字符串 | upper | string | `str → str`（Unicode simple case mapping） |
| | to_runes | string | `str → [rune]` |
| JSON | parse | json | `str → Json`（T1 宿主不透明值透传，决策 28） |
| | stringify | json | `Json → str`（T1 透传解析文本） |
| 解析 | parse_int/parse_float | — | `str → T?`（失败 = None，决策 27 通道） |

**print 语义注记（设计债登记，非缺陷）**：print 为 **display 语义**（字符串不带引号，沿 Lua/Python 人类默认；输出走宿主缓冲通道，决策 73）。这意味着 `print("42")` 与 `print(42)` 输出逐位相同——调试场景下无法区分字符串与数值。AI 原生场景里 repr/debug 语义有真实价值（Agent 消费结构化输出时需类型可辨）。**裁决**：不改 print（display 是正确的打印默认，repr 不是）；设计债 = 未来 io 模块增加 `io.debug(...)` 变体（repr 语义：字符串带引号转义、区分 int/float），在 io 能力包落地时（阶段 5/6）一并裁决，届时一并考究嵌套容器的 repr 深度（deep_eq/display 已有深度截断先例，23-T2 §8.3）。

**访问模型**（决策 25/76/78）：每个内建可裸名调用（数据第一参数）；`module` 字段是命名空间别名糖（`math.sqrt` ≡ `sqrt`，含值位，决策 78）；`import模块.函数` 限定调用在 lower 归一为同一 bare 名分派。**std 模块面需显式 import**（19.2 单一命名空间；未用 import 触发 W-T0003）。**裸名内建恒可用、不设 import 门**（决策 78）：gate 只画在能力面（I/O/FS/网络经宿主注入，未注入 = 编译期 Y-T0001，决策 76），纯计算内建（math/string/json）不授予能力，设 import 门是 security theater。**结构先例**（23-T2 第二回合 §8.1 更正）：Yoru 的平坦全球名面 = **GDScript @GlobalScope 模型**（官方清单实证：abs/floor/ceil/clamp/lerp/sin/cos/atan2/sqrt/pow/exp/log/min/max/print/len/range 全部裸名），非 Python 模块模型（Python `floor` 无 import = NameError）——Yoru 比 Python 更平坦；Python 的贡献在哲学侧：Guido 原文「**关键词才是稀缺资源，builtins 是廉价资源**」（可遮蔽、增不破旧），与 lower「局部遮蔽优先」同构。

**全球名面准入政策**（23-T2 §8.2，T-A 线程；对新成员生效，不清洗现有 26 条）：三测全过才进裸名全球面——① **普遍性**：Python/JS/GDScript 三大 AI 语料同形同语义（len/abs/min/max/print/range 过；smoothstep/wrapf 不过——GDScript 有、另两家无）；② **无能力**：不授予 I/O/FS/网络（决策 76 能力面不变）；③ **总览性**：语义一句话可穷尽、无隐藏状态。政策依据：Python builtins 策展实践（含 reduce 裁出，PEP 219）证明全球名面应策展而非无限；阶段 5 `using` 注入式 import（J1）落地后压力部分转移，但准入仍必要（注入亦是名字来源，须可静态枚举）。

**宿主对象环之约定**（23-T2 §8.3 / 决策 79）：语言层循环引用不可构造（自捕获初始化被 Y-T0001 挡；变异成环需无穷递归类型），宿主注入对象若自带环，卫生归宿管——VM 的 deep_eq/display 有深度截断 + Rc 指针短路（不爆栈），run 作用域堆信封（决策 79）保证单 run 内总量有界。

**Map 缺键契约（fail-soft 索引 + fail-loud 解包）**（决策 55；27 号 A1 裁决）：`m[k]` 缺键返回 `V?` 的 None（**类型化，非裸 nil**），`let x: int = m[k]` 编译期被拦、`m[k]!` 缺键运行期 Y-R9015 崩溃——「静默毒化下游」不成立，类型闸完备。真实缺口是**惯用法断层**：Option 模式匹配未落地（26 号 D-18）、stdlib 无 `map.get`/`get_or` 语义函数。排期：`map.get/get_or` 随 stdlib 增量补（无语法变更）；惯用法落地依赖 D-18。当前推荐写法：nil 收窄（`if m[k] != nil`）或 `!`（确定存在时）。

**json T1 边界（决策 28；82 号审计注记）**：Json 为宿主不透明透传值——`parse` 存解析文本、`stringify` 取回文本，**不构造结构化值**。因此 `stringify(nil)`/`stringify(42)` 被拒是 T1 刻意边界（Json 值域 = parse 产物），非缺陷；结构化 Json（nil→null 序列化、int→Json 便捷通道）属阶段 2+，待数值塔/结构化 JSON 批次。

**Param 封闭 DSL**：`Int/Float/Number/Str/Bool/Unit/Json/Rune/Any/List/MapKV/Range/Collection/Fn/Var/Opt`，`&'static [Param]` const 可构造（零分配、无 Box）。

**软类型仅存于内建面**：`Ty::Num`（int|float）/`Ty::Coll`（str|list|map）/`Ty::Any`，`same()` 按成员集判定，用户不可书写。

## 6.3 领域能力A：游戏数学 math3d

定位：向量/矩阵/四元数标准库，参考 glam（Rust 游戏数学事实标准）与 wgpu-matrix（WebGPU 约定）。

- 类型：vec2/vec3/vec4、mat3/mat4、quat（struct + 值语义，字段 x/y/z/w）。
- MVP：函数式 API（wgpu-matrix 风格：vec3.add/mul/dot/cross/normalize/length/lerp；mat4.identity/mul/transpose/invert/translation/rotationX/Y/Z/perspective/ortho/lookAt）。
- P1：dest/out 参数模式减少分配（wgpu-matrix/Vornmath 模式）；quat 完整（slerp/axis-angle）；f32 类型（图形学标配，glam 以 f32+SIMD 为主）。
- P2：受限运算符重载（仅标准库数学类型，glam/Unity 风格）；swizzle（v.xyz）。
- 投影约定：多约定 API 后缀（m2s2-math 的 _rh_zo/_lh_no 模式），宿主无关关键设计（WebGPU 深度 [0,1] vs WebGL [-1,1]）。
- P3：SIMD 布局保证（与 AOT 配合）。

## 6.4 领域能力B：底层运算

- MVP：位运算符（& | ^ << >> >>>）、int/float、显式转换。
- P1：精确宽度整数 u8-i64、f32、ByteArray buffer（二进制协议、图形数据，越界返回 Result）。
- 沙盒约束：脚本无裸指针、无直接内存访问；buffer 是标准库类型，内存操作经宿主。

## 6.5 领域能力C：图形学、驱动、跨平台 API/SDK

- 原则：内核不内置图形/驱动/平台 API；wgpu/Vulkan/GL/DX 全部由宿主 Rust 提供，经 FFI 暴露。
- 内核贡献：确定性数值语义（多投影约定可移植）、值语义（绑定友好，无共享状态）、FFI 低拷贝方向（P1 zero-copy）、布局确定性（P2）。
- 跨平台路径：VM 可运行于 WASM（Web），宿主注入图形能力。

## 6.6 性能方向

- 解释器：opcode fusion + 多态内联缓存（QuickJS-ng 验证，P1）。
- 编译：增量编译（P1）。
- 执行：单层 JIT（P2）、AOT 双后端（P3）。
- 内存：引用计数（MVP）→ 区域释放（P2）。
