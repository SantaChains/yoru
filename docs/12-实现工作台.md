## 12.2 设计13：宿主 API 契约（Rust，签名级定稿）

`l-ffi` 对外 API（MVP 完整形态，不暴露任何内部对象裸指针）：

```rust
// 值表示（l-vm 导出）
pub enum Value {
    Int(i64), Float(f64), Bool(bool), Unit, Nil,
    String(Rc<str>),
    List(Rc<RefCell<Vec<Value>>>),        // P1 改 COW 值语义优化
    Map(Rc<RefCell<BTreeMap<Value, Value>>>),
    Struct(Rc<StructData>),               // 字段值拷贝语义，数据不可变共享
    Closure(Rc<Closure>),
    HostFn(Rc<HostFnData>),
}

// 配置与诊断
pub struct VmConfig {
    pub max_memory_bytes: usize,          // 0 = 默认（如 64MB）
    pub max_instruction_budget: u64,      // 执行预算，0 = 默认
    pub max_call_depth: u32,              // 显式调用栈上限（沙盒关键）
    pub strict_by_default: bool,          // false = nonstrict
}
pub struct Diagnostic {
    pub severity: Severity,               // Error | Warning | Info
    pub message: String,                  // 人类可读
    pub span: Option<Span>,               // 源码位置（文件、行、列、长度）
    pub suggestions: Vec<String>,         // 修复建议（P1 全量）
    pub json: serde_json::Value,          // 结构化输出（AI 可定位修复）
}

// 主入口
pub struct Vm { /* 私有字段 */ }
pub struct ModuleId(u32);

impl Vm {
    pub fn new(config: VmConfig) -> Vm;
    pub fn load_module(&mut self, source: &str) -> Result<ModuleId, Vec<Diagnostic>>;
    pub fn call_fn(&mut self, module: ModuleId, name: &str, args: &[Value])
        -> Result<Value, VmError>;                          // VmError 含运行时错误+诊断
    pub fn reload_module(&mut self, id: ModuleId, source: &str)
        -> Result<(), Vec<Diagnostic>>;                     // 热重载（丢弃旧顶层状态，Lua require 语义）
    pub fn register_host_fn<F>(&mut self, name: &str, sig: HostSig, f: F)
        -> Result<(), FfiError>
        where F: Fn(&mut Vm, &[Value]) -> Result<Value, VmError>
             + Send + Sync + 'static;                       // 能力注入（沙盒唯一通道）
    pub fn set_interrupt(&mut self, cb: impl FnMut(&mut Vm) -> Interrupt); // 超时/用户中断
    pub fn memory_used(&self) -> usize;                     // 资源监控（soak 用）
}

pub struct HostSig {                                        // 类型检查时校验 CallHost
    pub params: Vec<TypeDesc>,
    pub ret: TypeDesc,
}
```

绑定宏（`l-ffi`，T0.6）：`#[derive(LValue)]`（Rust struct ↔ Yoru struct 自动绑定）、`#[l_command(name = "...")]`（函数注册为宿主命令）。签名校验在类型检查阶段完成（CallHost 指令带签名）。

设计要点：句柄 + Result 模式（无裸指针暴露 GC 对象，规避 Python C API 悬挂引用问题）；宿主不触碰 VM 内部对象；错误以 Result 返回（Lua protected call 思路，见 [09-学习借鉴](09-学习借鉴.md) 9.5）。

## 12.4 阶段0 验收清单（退出即声明 MVP 完成）

- [ ] 示例脚本可运行（hello、变量/函数/结构体/match/循环）。

- [ ] Rust 宿主双向调用通过（脚本调宿主函数、宿主调脚本函数，含 derive 绑定）。
- [ ] 资源限制生效（死循环被超时终止、内存上限触发、栈深上限触发）。
- [ ] 测试套件全绿：分层测试 + 边界矩阵 + 四层 fuzz ≥24h 无崩溃（发布门槛，[10-抗冲击测试体系](10-抗冲击测试体系.md) 10.6）。
- [ ] 覆盖率报告：核心 ≥90% 分支。
- [ ] 诊断 JSON 稳定（AI 可解析修复）。
